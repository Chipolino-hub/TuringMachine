# TuringMachine

Графический учебный симулятор **машины Тьюринга** на Java и JavaFX.

## Возможности

- Настройка алфавита, состояний и таблицы переходов.
- Ввод ленты и выполнение шагов машины Тьюринга.
- Визуализация состояний и результатов работы.

## Запуск

1. Установите **JDK 21** и Maven (или используйте прилагаемый Maven Wrapper).
2. В папке проекта выполните `./mvnw javafx:run` (Windows: `mvnw.cmd javafx:run`).
3. Для запуска из IDE откройте Maven-проект по `pom.xml`.

## Структура

- `src/main/java/` — реализация машины и JavaFX-контроллер.
- `src/main/resources/` — FXML-разметка и стили.
- `pom.xml` — зависимости Maven, включая JavaFX 21.

В архиве опубликован только исходный проект без результатов сборки, локальных конфигураций IDE и персональных данных. Полный запуск интерфейса не проверялся.
